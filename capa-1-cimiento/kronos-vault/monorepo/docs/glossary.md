## 📖 Términos

### 🎭 Capa simbólica

> Sistemas de interpretación cultural: astrología, numerología, quiromancia, salmos, textos herméticos. Se tratan como **narrativa**, no como ciencia.

### 📐 Capa lógica

> Transformación de símbolos en datos estructurados: fechas, números, categorías, reglas verificables.

### ⚙️ Capa computacional

> Análisis mediante algoritmos, inteligencia artificial o simulación matemática. **No implica hardware cuántico real.**

### 🕰️ Capa de tiempo

> Organización de eventos, ciclos, versiones, decisiones y cambios históricos.

### 🎨 Capa de interfaz

> Presentación visual de resultados: mapas, gráficos, tablas, explicaciones.

### 🧮 Simulación cuántica

> Modelo **matemático** que imita el comportamiento probabilístico de sistemas cuánticos. Es software, no tecnología cuántica física.

### 🌐 Deep web

> Contenido no indexado por buscadores: plataformas internas, archivos académicos, correos, cuentas protegidas. **No es ilegal por sí misma.**

### 🕶️ Dark web

> Subconjunto pequeño de la deep web que requiere redes especiales de acceso. Puede usarse para privacidad o para actividades ilegales. **No es una dimensión espiritual ni cuántica.**

### 🔺 Tercera capa (en CRONOS)

> Metáfora **narrativa interna**: el sistema que interpreta patrones, identidad, tiempo y decisiones. No es una red secreta real.

### 📅 Timeline

> Línea temporal que organiza ciclos, fechas, versiones y acontecimientos dentro del sistema.

### 🎴 Corpus simbólico

> Conjunto de datos culturales (astrológicos, numerológicos, quirománticos, textuales) tratados como referencia interpretativa, no como fuente de verdad.

### 🧠 Motor simbólico

> Componente que **interpreta** el corpus simbólico. No decide, no predice. Traduce cultura a estructura.
