## ✅ Compromisos

| Compromiso | Cómo se cumple |
|------------|----------------|
| Transparencia | README raíz incluye aviso explícito sobre qué es real y qué es narrativa |
| Separación | Cada capa está documentada por separado, sin mezclar |
| Revisión | Toda contribución a `data/symbolic/` requiere fuente cultural |
| No predicción | Ningún módulo devuelve "predicciones" ni "resultados garantizados" |
| Código abierto | Licencia MIT, sin cláusulas ocultas |
| Accesibilidad | Sitio funcional sin JS, sin dependencias externas críticas |

---

## 🧠 Ética programática

Más allá de la documentación, el código mismo debe respetar estos principios:

1. **Ningún endpoint devuelve "predicciones".** Solo interpretaciones etiquetadas.
2. **Ninguna función oculta sus transformaciones.** Todo es trazable.
3. **Ningún módulo confunde simbólico con lógico.** Se validan los límites en los tests.
4. **Toda salida incluye disclaimer** cuando involucra contenido simbólico.

---

## 🎭 Advertencia sobre interpretación simbólica

El corpus simbólico (astrología, numerología, quiromancia, textos) es **patrimonio cultural**. Se trata con respeto:

- No se ridiculiza.
- No se presenta como ciencia.
- No se usa para manipular emocionalmente.
- No se explota comercialmente como "predicción".

Se estudia, se documenta y se traduce a estructura. Nada más. Nada menos.
