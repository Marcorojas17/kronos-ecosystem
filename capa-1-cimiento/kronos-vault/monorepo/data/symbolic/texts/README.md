## 🎯 Propósito

Recopilar textos simbólicos de referencia como **patrimonio cultural** para:

1. Documentar la tradición textual hermética y devocional.
2. Servir de materia prima para análisis simbólico (repeticiones, estructuras, temas).
3. Estudiar cómo los textos sagrados o herméticos se reinterpretan a lo largo del tiempo.

## ✅ Requisitos para contribuir

Toda entrada nueva debe incluir:

1. **Tradición y contexto** (hebrea, griega, egipcia, europea, etc.).
2. **Fuente textual o referencia** clara.
3. **Temas y estructura** identificados.
4. **Declaración** `"computational_claim": false`.
5. **Etiqueta** `#cultura` o `#narrativa`.
