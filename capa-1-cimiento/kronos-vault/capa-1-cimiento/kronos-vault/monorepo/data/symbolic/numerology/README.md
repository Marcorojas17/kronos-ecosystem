## 🎯 Propósito

Recopilar material numerológico de referencia como **patrimonio cultural** para:

1. Documentar cómo distintas tradiciones asignan significado a los números.
2. Servir de materia prima para la **capa lógica** (reducción, ciclos, patrones).
3. Estudiar la relación entre símbolo numérico y estructura matemática.

## ✅ Requisitos para contribuir

Toda entrada nueva debe incluir:

1. **Tradición de origen** (pitagórica, cabalística, mesoamericana, etc.).
2. **Regla de cálculo** explícita y reproducible.
3. **Etiqueta** `#cultura` o `#narrativa`.
4. **Distinción clara** entre "significado tradicional" y "uso en CRONOS".
