## ⚠️ Advertencia sobre el corpus simbólico

El contenido de `symbolic/` se trata **exclusivamente como material cultural y narrativo**.

```text
╔══════════════════════════════════════════════════════════════════════════╗
║                                                                          ║
║   ✗  NO es ciencia                                                       ║
║   ✗  NO predice                                                          ║
║   ✗  NO sustituye asesoría profesional                                   ║
║                                                                          ║
║   ✓  ES cultura                                                          ║
║   ✓  ES narrativa                                                        ║
║   ✓  ES material de referencia                                           ║
║                                                                          ║
╚══════════════════════════════════════════════════════════════════════════╝
```

Toda contribución a esta carpeta debe incluir:

1. Fuente o referencia cultural.
2. Contexto histórico cuando aplique.
3. Etiqueta `#cultura` o `#narrativa` en el encabezado del archivo.
