# Política de seguridad — CRONOS

## Alcance

Este repositorio aloja el **sitio estático** del Proyecto Cronos (HTML, CSS, JavaScript vanilla) y su **documentación conceptual**. No contiene backend, base de datos ni procesamiento de datos de usuarios.

## Versiones soportadas

| Versión | Soportada |
|---------|:---------:|
| `main` (actual) | ✅ |
| Ramas antiguas | ❌ |

## Cómo reportar una vulnerabilidad

**No abras un issue público** para reportar problemas de seguridad.

Usa **GitHub Private Vulnerability Reporting**:

1. Ve a la pestaña **Security** del repositorio.
2. Pulsa **Report a vulnerability**.
3. Describe el problema con el mayor detalle posible.

También puedes escribir directamente a:

**marcorojas17@users.noreply.github.com**

## Qué incluir en el reporte

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto potencial.
- Versión o commit afectado.
- Sugerencia de mitigación (si la tienes).

## Tiempos de respuesta

| Etapa | Plazo objetivo |
|-------|:--------------:|
| Acuse de recibo | 72 horas |
| Evaluación inicial | 7 días |
| Corrección (si aplica) | 30 días |

## Qué NO se considera vulnerabilidad

- Predicciones simbólicas (el proyecto no predice).
- Falta de contenido en carpetas aún no implementadas (`src/`, `tests/`).
- Estilos visuales.
- Enlaces externos caídos.
- Interpretaciones astrológicas, numerológicas o quirománticas.

## Reconocimiento

Agradecemos los reportes responsables. Si lo deseas, podemos acreditarte en el `CHANGELOG.md` al publicar la corrección.
