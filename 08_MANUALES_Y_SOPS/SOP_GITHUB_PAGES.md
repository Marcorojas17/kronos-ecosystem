---

```
[kronos@08 ~]$ ./kronos --pasos
```

**PASO 1 · Crear el repositorio**

```
[1] ▸ Ir a github.com/new
[2] ▸ Nombre: kronos-ecosystem
[3] ▸ Visibilidad: Public
[4] ▸ Inicializar con README
[5] ▸ Create repository
```

**PASO 2 · Subir los archivos**

```
[1] ▸ Add file → Create new file
[2] ▸ Escribir ruta: index.html
[3] ▸ Pegar contenido
[4] ▸ Commit con emoji
```

**PASO 3 · Activar Pages**

```
[1] ▸ Settings → Pages
[2] ▸ Source: Deploy from a branch
[3] ▸ Branch: main
[4] ▸ Folder: / (root)
[5] ▸ Save
```

**PASO 4 · Verificar**

```
[1] ▸ Esperar 2-3 minutos
[2] ▸ Abrir: https://USUARIO.github.io/kronos-ecosystem/
[3] ▸ Si carga → ✅ Éxito
[4] ▸ Si no carga → revisar branch y folder
```
